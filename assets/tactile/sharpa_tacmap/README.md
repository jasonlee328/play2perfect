# Sharpa TacMap fingerpad maps

Per-pixel elastomer surface points and outward normals (240x240, mm) for the Sharpa hand's
fingerpads: `4F` = index/middle/ring/pinky, `TH` = thumb. Copied unmodified from
[sharpa-robotics/sharpa-tacmap](https://github.com/sharpa-robotics/sharpa-tacmap)
(`assets/tactilesensor_map/`, commit e4f8827) under the Apache-2.0 license in this directory.
Used by `isaacsimenvs/tasks/play/utils/tactile_utils.py`.
